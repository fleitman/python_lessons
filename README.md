## 🧪 Образовательные методологии

Каждый уровень использует **4 разных подхода** к обучению:

<details>
<summary><b>1. PRIMM</b> (Predict → Run → Investigate → Modify → Make)</summary>

- **Predict**: Предскажите, что сделает код
- **Run**: Запустите и проверьте
- **Investigate**: Исследуйте, как работает (через эксперименты!)
- **Modify**: Измените код по заданию
- **Make**: Создайте свой код с нуля

📖 **Цель**: Научиться читать код ПЕРЕД тем, как писать свой

</details>

<details>
<summary><b>2. Parson Problems</b> (Сборка кода из перепутанных строк)</summary>

- Даны все строки кода (но перепутаны)
- Нужно расставить в правильном порядке
- Есть лишние/неправильные строки (отвлекающие)

📖 **Цель**: Понять структуру программы без синтаксических ошибок

</details>

<details>
<summary><b>3. Test-Driven Development (TDD)</b></summary>

- Тесты уже написаны
- Нужно написать код, чтобы все тесты прошли ✅
- Видно что ожидается на каждом шаге

📖 **Цель**: Научиться писать код под чёткие требования

</details>

<details>
<summary><b>4. Block Programming</b> (Блочное программирование)</summary>

- Визуальное программирование (как конструктор LEGO)
- Нет синтаксических ошибок
- Фокус на логике, а не на синтаксисе

📖 **Цель**: Понять алгоритмы без кода

</details>

### Для студентов:

1. **Начните с теста уровня** (в папке level0/1/2 есть описание)
2. **Откройте файл** в IDLE / VS Code / PyCharm / онлайн-редакторе
